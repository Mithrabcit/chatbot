An AI-powered chatbot built using FastAPI, Google Gemini API and Streamlit. The application accepts dynamic user questions through a simple web interface, processes them using a FastAPI backend and generates responses using Google's Gemini model.

About the Project

This project demonstrates the development of an AI chatbot by integrating a Large Language Model (LLM) with a Python backend.

The application allows users to enter questions through a Streamlit interface. These questions are sent to a FastAPI endpoint, which communicates with the Gemini API and returns the generated response to the frontend.

Tech Stack

- Programming Language: Python
- Backend Framework: FastAPI
- AI Model: Google Gemini 3.1 Flash-Lite
- Frontend: Streamlit
- API Communication: HTTP Requests
- Data Format: JSON

Features

- Interactive chatbot interface.
- Dynamic user question input.
- Integration with Google Gemini API.
- FastAPI-based REST API endpoint.
- Real-time question and answer communication.
- Error handling for API communication.
- Separation of frontend and backend.
